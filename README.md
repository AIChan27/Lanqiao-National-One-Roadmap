## 🚀 省赛阶段（通往国赛的门票）

### 阶段一：寒假前（11月底 - 1月10日）
*   **目标**：15 个考点单元全部通关（限时验证一次 AC），**不碰真题**。
*   **节奏**：一天 1–2 道，一周 6–10 道。通关优先于数量，12 道是上限不是 KPI。
*   **每个单元 2–4 题**：`学习`（可看题解，关掉重写）→ `验证`（限时 30 分钟，不看题解，一次 AC）→ `迁移`（同考点、提高−/提高、换个包装）。
*   **15 个单元**：
    *   *基础 7*：排序 / 二分 / 双指针 / 前缀和差分 / 枚举 / DFS-BFS / 贪心
    *   *主力 5*：线性 DP+背包 / 区间 DP+LIS / 图论 / 数学基础 / 数据结构
    *   *补充 3*：位运算状压 / 组合期望 / 字符串
*   **周排期**：

| 周 | 日期 | 单元 | 题数 |
| :--- | :--- | :--- | :---: |
| W0 | 11/27–11/30 | ① 排序 | 2 |
| W1 | 12/01–12/06 | ② 二分 + cacc 找感觉 3 题 | 6 |
| W2 | 12/07–12/13 | ③ 双指针 ④ 前缀和差分 ⑤ 枚举 | 7 |
| W3 | 12/14–12/20 | ⑥ DFS/BFS ⑦ 贪心 ⑫ 数学基础 | 8 |
| W4 | 12/21–12/27 | ⑧ 线性 DP ⑨ 区间 DP/LIS | 7 |
| W5 | 12/28–01/03 | ⑩ 状压 ⑪ 图论 | 7 |
| W6 | 01/04–01/10 | ⑬ 组合期望 ⑭ 字符串 ⑮ 数据结构 | 10 |

*   **cacc（12/06）**：裸考找感觉，赛前 3 天做 3 道“题面适应”题（模拟/字符串/DFS），不追分、不改节奏。
*   **通关标准**：验证题 30 分钟内、不看题解、一次 AC；两次没过就停下看教材，不硬赶。
*   **失败处理**：某单元没通关，顺延到下一周；到 1/10 仍没过的，寒假第一周补，不占寒假主线。
*   **明确推迟到寒假**：真题套卷、4 小时摸底、Dev-C++ 5.11 环境、模板库统一整理。
*   **不能等的事**：确认学校报名（多数 12/18 截止，报名费 300 元）。

### 阶段二：寒假（1月中旬 - 2月底，黄金窗口期）
*   **目标**：完成从“ACM思维”到“蓝桥得分思维”的切换。
*   **主线**：每周 2 套 4 小时省赛真题 + 2 小时复盘；弱项补漏；大模拟每周 1 道；国赛专题 3 个（线段树 / 树形 DP / 数位 DP）每周 2 小时。
*   **不再开新的省赛单元**（阶段一已完成 15 个），寒假只做“套卷 + 补弱 + 国赛”。
*   **死磕规则**：15 分钟无正解思路，立刻写暴力拿部分分；每道题至少提交一次。
*   **留卷**：2025/2026 两套留到 3 月考前。

### 阶段三：开学后至省赛（3月 - 4月）
*   **目标**：碎片化时间保持模拟频率，固化得分策略。
*   **工作日**：每天 30-45 分钟默写模板 + 1道真题填空/简单编程。
*   **周末**：半天时间进行 1 次完整省赛真题限时模拟并复盘。

## 👑 国赛阶段（国一攻坚）

> *（注：进入国赛后再细化。核心增量为：数学思维 + 综合建模）*

*   **省赛已覆盖（阶段一）**：并查集、树状数组、KMP、最短路、拓扑排序、二分答案、离散化、快速幂、组合数。
*   **国赛增量**：线段树、树形 DP、数位 DP、数论进阶（欧拉 / CRT）、组合计数进阶（容斥 / 卡特兰）、矩阵快速幂、分治 / 倍增。
*   **国赛演练**：每周 2 次 4 小时全真模拟，拆解难题的“模块拼接”。
