## 🚀 省赛阶段（通往国赛的门票）

### 阶段一：寒假在校前（11月底 - 1月中旬）
*   **目标**：不冷掉！维持 C++ 语法与输入输出肌肉记忆。
*   **策略**：每天至少1道题（20-30分钟）。不碰复杂算法。
*   **「20选」康复标签池（洛谷）**：
    *   *难度限制*：`入门` / `普及-`
    *   *语言基础*：`语言入门`、`数组`、`字符串`、`STL`
    *   *蓝桥最爱*：`模拟`、`枚举`、`排序`、`贪心`、`递推`
    *   *线性结构*：`前缀和`、`差分`、`栈`、`队列`、`哈希表`
    *   *搜索与数学*：`DFS`、`BFS`、`二分`、`进制`、`素数判断`、`gcd`
*   *异常处理*：卡住 20 分钟直接看题解 -> 关掉题解自己敲 AC。

### 阶段二：寒假（1月中旬 - 2月底，黄金窗口期）
*   **目标**：完成从“ACM思维”到“蓝桥得分思维”的切换。
*   **前半段（专题恢复）**：每天 3-4 小时，专项刷上述标签，补齐生疏模块。
*   **后半段（全真模拟）**：每周 2 次 4 小时省赛真题模拟。**死磕规则**：15分钟无正解思路，立刻写暴力拿部分分！

### 阶段三：开学后至省赛（3月 - 4月）
*   **目标**：碎片化时间保持模拟频率，固化得分策略。
*   **工作日**：每天 30-45 分钟默写模板 + 1道真题填空/简单编程。
*   **周末**：半天时间进行 1 次完整省赛真题限时模拟并复盘。
