# 🏆 2027 蓝桥杯国一冲刺计划 (Lanqiao Cup National One Roadmap)

> **背景**：2016年 ACM-ICPC 亚洲区域赛铜牌；十年未碰算法；现深度学习研一（PyTorch/C++大模型底层）。
> **目标**：2027年蓝桥杯研究生组 国一。
> **策略**：坚持使用 C++ 比赛；以洛谷为核心刷题平台，LanqiaoOJ 为全真模拟平台。

## 🛠️ 赛前准备：工具与资料库
*   **核心题库**：洛谷（主）、LanqiaoOJ（辅，用于真题模拟）
*   **参考书籍**：紫书《算法竞赛入门经典》、《挑战程序设计竞赛》、蓝书《算法竞赛进阶指南》
*   **在线字典**：OI Wiki（随用随查，不系统读）

---

## 🚀 省赛阶段（通往国赛的门票）

### 阶段一：寒假在校前（11月底 - 1月中旬）
*   **背景**：准备四六级与期末考试，算法仅作低功耗后台任务。
*   **任务目标**：**不冷掉！维持 C++ 语法与输入输出的肌肉记忆。**
*   **执行策略**：每天至少1道题（20-30分钟）。不碰复杂算法，不找虐。
*   **「20选」康复标签池（洛谷）**：
    *   **难度限制**：`入门` / `普及-`
    *   **语言与基础**：`语言入门`、`数组`、`字符串`、`STL`
    *   **蓝桥最爱**：`模拟`、`枚举`、`排序`、`贪心`、`递推`
    *   **线性结构**：`前缀和`、`差分`、`栈`、`队列`、`哈希表`
    *   **基础搜索**：`深度优先搜索 DFS`、`广度优先搜索 BFS`
    *   **基础数学**：`二分`、`进制`、`素数判断`、`最大公约数 gcd`
*   **异常处理**：20分钟没思路直接看题解 -> 理解思路 -> 关掉题解自己敲一遍 AC。

### 阶段二：寒假（1月中旬 - 2月底，黄金窗口期）
*   **任务目标**：完成从“ACM思维”到“蓝桥得分思维”的切换；基础模型恢复到“不假思索写对”。
*   **前半段（专题恢复 + 真题精做）**：每天3-4小时。使用上述「20选」标签池中你感到生疏的模块进行专项刷题（如DP基础、搜索剪枝、图论基础）。
*   **后半段（全真模拟 + 暴力得分）**：每周2次严格4小时省赛真题模拟（LanqiaoOJ）。**死磕一条规则**：15分钟无正解思路，立刻写暴力拿部分分！

### 阶段三：开学后至省赛（3月 - 4月）
*   **任务目标**：在碎片化时间中保持模拟频率，把得分策略练成条件反射。
*   **工作日（30-45分钟）**：不碰新题，每天默写1个模板 + 1道真题填空/简单编程。
*   **周末（半天）**：1次完整省赛真题限时模拟。复盘记录暴力得分情况。

## 👑 国赛阶段（国一攻坚）

> **前提**：必须先稳稳拿下省一，进入国赛。省赛（4月中旬）与国赛（6月中旬）之间有约2个月的黄金冲刺期。
> *（注：具体计划待顺利进入国赛后，再行细化更新。当前先做高阶标签储备）*

**国赛核心增量为：数学思维 + 综合建模。**

*   **预研高阶标签池（来自洛谷）**：
    *   **数学向**：`数论`、`组合数学`（容斥、排列组合、卡特兰数等）、`快速幂`、`逆元`、`进制`、`模运算`。
    *   **数据结构向**：`并查集`、`树状数组`、`线段树`（维护非求和信息的变体）。
    *   **字符串向**：`KMP算法`、`字符串hash`。
    *   **图论向**：`最短路 (Dijkstra)`、`拓扑排序`、`最小生成树`。
    *   **综合技巧**：`二分答案`、`双指针`、`离散化`、`前缀和与差分`的高阶应用。
*   **国赛模拟**：每周2次严格4小时全真模拟。复盘时拆解每道难题的“模块拼接方式”。
